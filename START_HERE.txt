DINOCADEMY v5.0.0
=================

1. Rozpakuj cały katalog projektu.
2. Otwórz terminal w katalogu projektu.
3. Uruchom:

   npm install
   npm start

4. Otwórz w przeglądarce:
   http://localhost:3000

Najważniejsze pliki:
- server.js                         backend/API i logika XP
- public/index.html                strona główna
- public/assets/cohesion-v5.css    końcowy wspólny system wizualny
- public/assets/site-shell.js      wspólny header, nawigacja i motywy
- public/assets/hatchery.js        wykluwarnia/kolekcja
- public/assets/forum.js           forum
- docs/REVAMP_V5_NOTES.md          lista zmian i wykonanych testów
