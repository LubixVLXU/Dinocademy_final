DINOCademy v6.0.0

1. Rozpakuj cały katalog.
2. Otwórz terminal w katalogu projektu.
3. Uruchom: npm install
4. Uruchom: npm start
5. Wejdź na adres pokazany przez serwer (domyślnie http://localhost:3000).

Najważniejsze zmiany v6:
- encyklopedia wróciła do wyglądu sprzed v5,
- naprawiony Plan Pro i rejestracja,
- dopracowana strona główna,
- znacznie mocniejsze mnożniki kart i leveli,
- wszystkie jajka nadal zdobywają XP jednocześnie.
